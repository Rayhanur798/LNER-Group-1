**LNER Fleet Performance Analysis**
This repository contains the code and analysis for the University of Westminster Data Science group project.

**Project Overview**
The aim of this project is to analyse operational disruption data from LNER fleet operations and develop predictive models to identify incidents that may cause high operational pressure.

**Datasets**
The project uses three key datasets:
Fleet Performance
Fleet Delay
Fleet Planning

**Methods Used**
Data cleaning and preprocessing
Exploratory Data Analysis (EDA)
Feature engineering
Decision Tree modelling
Logistic Regression
Random Forest

**Repository Structure**
data/ – cleaned datasets
notebooks/ – analysis and modelling code
output/ – visualisations and model results
reports/ – written report components
